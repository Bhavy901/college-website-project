## Project Overview
An interactive academic engineering and research platform for HDLC bit stuffing and framing protocols.
Features:
- Real-time 3D WebGL physical link transmission simulation (Three.js).
- Interactive bit inspector and protocol pipeline (Input -> Stuffing -> Framing -> Destuffing).
- Mandatory test benchmark suite with empirical overhead analysis.
- Solved 7-mark CHARUSAT university examination numerical problem.
- Downloadable academic assessment packages (Presentation Slides, Technical Report, and Exam Solutions).

## Quick Start
Open `index.html` in any modern web browser or serve statically using:
```bash
python3 -m http.server 8080
```
Visit `http://localhost:8080` in your browser.
